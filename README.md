# DSS-Ky9

Môn học: **Hệ Hỗ Trợ Quyết Định (Decision Support Systems - DSS)** — Kỳ 9

Repository lưu trữ các bài tập lớn, đồ án giữa kỳ (GK) và cuối kỳ (CK) môn học Hệ trợ giúp ra quyết định.

---

## 📂 Danh mục đề tài

### 1. [Giữa kỳ (GK) - CFID Algorithm Visualizer](./GK)
- **Tên đề tài**: Trực quan hóa thuật toán lọc cộng tác có xét đến độ bất đồng nội bộ nhóm (Collaborative Filtering with Intragroup Divergence - CFID).
- **Bài báo tham chiếu**: *"A Collaborative Filtering Algorithm with Intragroup Divergence for POI Group Recommendation"* (Appl. Sci. 2021, 11(12), 5416).
- **Công nghệ**: React 19, TypeScript, Vite, KaTeX, Lucide Icons, Vitest.
- **Tính năng**: Mô phỏng toàn diện 8 bước thuật toán, tính điểm CF và độ phân kỳ, trực quan hóa ma trận và công thức toán học KaTeX, tương tác điều chỉnh tham số $\theta$, $\alpha$, Top-$k$.
- Chi tiết xem tại: [`GK/README.md`](./GK/README.md).
